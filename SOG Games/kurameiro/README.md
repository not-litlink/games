# 暗めいろ — 遊べるMVP

「その道、さっきも通った？」

## 起動

Node.js 20.19以上 / 22.12以上の現行環境を推奨（開発確認はNode 25）。

```sh
cd /Users/s/SOG Games/kurameiro
npm install
npm run dev -- --port 5178
```

ブラウザで http://127.0.0.1:5178/ を開く。

```sh
npm test
npm run build
npm run preview -- --port 4178
```

`dist/` が静的配信用成果物。Cloudflare Pages等ではプロジェクトのルートを `kurameiro`、ビルドを `npm run build`、出力を `dist` にする。サブディレクトリにも配置可能な相対アセット指定。公開・既存サイトへのリンク追加は今回実施していない。別端末への共有には公開URLが必要。ローカルURLは同じMac内での確認用。

## 実装した機能

### 検索・共有向けの公開ファイル

`npm run build` は、型チェック・Viteのビルド後、ホーム画面と紹介文を `dist/index.html` に事前出力します。検索ロボットがJavaScriptを実行しなくても、タイトル・見出し・遊び方・FAQ・フッターリンクを読めます。ゲーム自体にはJavaScriptが必要です。

gamesへの移行先は `/Users/s/SOG Games/kurameiro/`。一覧からのリンクは `/kurameiro/dist/` のままです。サイト全体の起動は親フォルダで `npm run dev`。ゲーム単体の開発は上記のViteコマンドを使います。

共有URLは実際に開いているURLから作られ、`?maze=` に同じ迷路・視界を保存します。親サイトのPythonサーバーでは `/kurameiro/dist/?maze=…` を使って確認します。`/kurameiro/` からの転送設定は既存の `_redirects` を親サイトに引き継いでいますが、Pythonサーバーはこの設定を解釈しません。

公開先ドメインは未定です。旧toolsドメインを指すcanonical・OGP URL・構造化データのURLは除去しました。公開時は確定したドメインでcanonical・OGPの絶対URL・構造化データ・サイトマップを設定してください。今回は公開・デプロイを行っていません。

- 9 / 15 / 21マス。既定15マス、トップから1回で開始。
- ランダムDFSで必ず接続した迷路を生成。壁1枚を取り除いてループを追加し、行き止まりも保持。BFSで最遠地点に出口を配置。
- WASD / 矢印キーの連続移動、正規化した斜め移動、タッチ用アナログスティック。
- 円形プレイヤーの衝突判定、細かい移動分割による壁抜け防止、軸別移動で壁沿いに滑る。衝突は接触開始ごとに1回。加算ペナルティなし。
- requestAnimationFrame、経過秒に基づく移動、指数補間によるカメラ追従。経過時間を25ms以下の物理ステップに分割し、低フレームレートでも移動速度を維持。
- グリッドDDAで最初の壁までのレイを計算。全方向のレイと近隣格子の角へのレイを使う視界ポリゴン。ポリゴン内だけ描画し、半径方向の減光を重ねる。壁の面は通路側への輪郭描画で表現し、遮蔽境界を壁の先へ広げない。過去の探索情報はプレイ画面に保持しない。
- Esc / ボタンで停止。タブ非表示・ウインドウのフォーカス喪失時も停止。復帰直後の背景滞在時間は計測から除外。停止時は迷路を完全に隠す。
- 結果にタイム・接触回数・歩いたマス数・全体図・実移動経路。マス数は最短経路と同じ数え方で比較し、実移動距離も内部記録。スライダーで移動履歴をたどれる。破線の最短経路を任意表示。
- 迷路メーカー：自動生成、壁・通路の追加、S/G位置変更、連続ドラッグ編集、1ストローク単位のUndo / Redo、テストプレイ。拡大編集は1マス44px。
- 編集中の孤立は許容し、テスト・共有直前に到達性を検査。外周とS/Gを壁にする編集は予防。
- URLはバージョン・サイズ・S/G座標・作問者の視界・壁ビット列・破損検出用チェックサムをBase64url化。標準視界の従来v1 URLも読み込み可能。共有URLは挑戦画面へ。形式・長さ・サイズ・境界・S/G・到達性を受信時に検証。
- コピー通知。Clipboard APIが使えない場合は選択できるURLと手動コピーの案内。
- 視界は標準2.5マス。エディターで作問者が2〜4マスに指定でき、共有URLに保存。プレイ中は固定。光量・速度・画面の動きを抑える設定はプレイヤーが調整可能。「初期設定に戻す」は作問者の視界を変更しない。操作設定をlocalStorageに保存（利用不可でもゲームは動作）。設定履歴も保持。
- レスポンシブ、セーフエリア、フォーカス表示、標準ダイアログのフォーカス制御、編集マスの矢印キー移動・Enter/Space編集、色に加えてS/G・実線/破線による識別。

## 技術構成とファイル

React 19 / TypeScript / Vite 7 / CSS / Canvas 2D。外部ゲームエンジン・画像・フォント配信・サーバー・DB・ログインを使用しない。

- `src/maze.ts`：生成、BFS、検証、共有、物理、レイ
- `src/render.ts`：壁、キャラクター、出口、遮蔽・光
- `src/Game.tsx`：ゲームループ、入力、停止、設定
- `src/Editor.tsx`：編集、履歴
- `src/MapView.tsx`：結果マップ・経路
- `src/main.tsx`：画面遷移、共有、結果
- `tests/maze.test.ts`：ロジックの自動テスト
- `qa/`：実際の画面と確認記録

## テスト

自動テスト15件：全サイズ各200迷路の到達性・ループ・分岐・行き止まり、共有往復・不正入力、到達不能の拒否、高速/斜め衝突、壁沿い移動、時間分割、BFS経路を連続移動で通れること、壁の遮蔽と角の遮蔽、v1/v2共有の互換性・視界の入力検証、設定初期化、距離とマス数の尺度。

Mac Chrome・Safariで共有挑戦URLからキーボード移動してクリア、結果表示まで確認。アプリ内ブラウザで15マス開始、390×844画面のスティック移動、停止、結果、編集・Undo/Redo、別タブで共有、壊れたURLからの復帰を確認。詳細は `qa/verification.md`。
